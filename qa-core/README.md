# qa-core Samples

Các file trong thư mục này là mẫu khởi đầu để copy sang `qa-core/` của repo implement thật.

- `workflows/manual-test-design.workflow.md`: workflow MVP.
- `skills/common/*`: đọc requirement và hỏi clarification.
- `skills/manual/*`: hiểu feature, tạo và review manual testcase.
- `skills/automation/*`: skill future cho Playwright POM, chưa dùng trong MVP Manual.

Lưu ý:

- Khi implement thật, cần bổ sung JSON Schema tương ứng trong repo code; bộ tài liệu này chỉ gửi các file `.md` theo yêu cầu.
- Skill thay đổi phải commit/version và được đánh giá bằng output thực tế trước khi coi là chuẩn mới.
